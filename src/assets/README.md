# GOBLIN EATER asset library

Add approved website artwork to these folders:

- `branding/` — wordmarks, logos and shared marks
- `stickers/` — individual sticker graphics and badges
- `illustrations/` — creatures, characters and decorative drawings
- `textures/` — grain, halftone, paper, noise and overlays
- `backgrounds/` — large scene and photographic backgrounds
- `product-graphics/` — product-specific print graphics and artwork

Use lowercase kebab-case filenames. Prefix artefact-specific files with the
artefact ID (for example `bog-dweller-`, `no-saints-`, `gutter-slime-`).
See the repository-root `DESIGN_WORKFLOW.md` for export formats and process.
